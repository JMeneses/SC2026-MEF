# SC2026-MEF
Um repositório que irá conter vários jupyter notebooks que contêm as aulas práticas de simulação computacional. Estes ficheiros podem ser abertos num software próprio ou importados para a Google Drive e abertos no Google Colab.

## A disciplina 
A disciplina de simulação computacional tem dois blocos temáticos, o primeiro bloco é dedicado ao processo do método de elementos finitos. Antes de cada aula é lançado um novo ficheiro neste repositório que servirá de base de trabalho. Cada ficheiro contém uma explicação teórica para leitura, um conjunto de exercícios resolvidos e um conjunto de exercícios de consolidação para realizar durante a aula prática.

## Como descarregar?
Para descarregar basta numa pasta do teu computador fazeres *git clone* deste repositório e para actualizar antes de cada aula deves abrir a pasta e correr um comando *git pull*.
PS: É necessário instalares o software de controlo de versões *git*;
